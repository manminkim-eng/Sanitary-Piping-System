루프·각개통기담당 배수관 1/2 이상, DN32 이상 · 12 m 이상 1단계 상향4.3.4(2)
🔩 최소 기울기 (표 4.1-1)
DN65 이하 : 1/50
DN80 ~ 150 : 1/100
DN200 이상 : 1/200
🔩 트랩 설치 기준
모든 위생기구 트랩 설치
봉수 깊이 : 50~100mm (별표 6)
2중 트랩 : 설치 금지
표에 없는 기구 최소 트랩 DN32
🌀 통기 방식
각개 통기 : 1기구 1통기관
루프 통기 : 수평지관 최상류 기구
신정 통기 : 수직관 상부 연장
통기수직관 정밀 산정 : 표 4.3-1(길이·DFU)
🏗️ 층수와 수직관
층수 = 브랜치 간격 수로 보고
4 이상이면 간격당 부하도 함께 검토
(전 층 균등 분포 가정 · 자동 적용)
🔗 입력값 ↔ 결과값 연관 관계도
각 입력 항목이 어떤 결과에 영향을 미치는지 구조적으로 정리합니다.
🏢 건물 용도 + 사용 용도 구분
WSFU·DFU 결정 → 순간최대유량 Q → 모든 관경
• 주거 / 공용 선택에 따라 같은 수량이라도 WSFU 가 달라져 급수 관경이 변동됨
• 건물 용도에 따라 표 4.1-2 DFU 열이 바뀌어 배수 관경이 변동됨
🏗️ 층수 × 층높이
정수두 계산 → 최상층 잔류압 + 환탕 자동판정 + 수직관 브랜치간격
• 정수두 = 층수 × 층높이 × 9.81 kPa/m
• 최상층 잔류압 = 급수압 - 정수두 - 마찰손실(추정) → 설치 기구 최저 필요수압(표 4.3-1) 미만 시 경고
• 층수×층높이×1.3(추정) > 15m → 환탕 배관 필요 판정
• 층수 = 배수수직관 브랜치 간격 수 → 표 4.1-5 열 선택(3 이하 / 4 이상)
⚡ 최대 허용 유속 (m/s)
유속기준 관경 역산 → 최소 호칭지름 → 실유속 표시
• D(mm) = √(4Q / π·V) 공식으로 최소 관경 역산
• 유속 낮출수록 → 관경 증가 / 유속 높일수록 → 관경 감소
• 유속 한계는 기준 수치가 없어 설계자가 정한다 (기본 1.5 m/s)
🔧 관재질 (Hazen-Williams C값)
강관(SGP)
C=100
스테인리스/동관
C=130
PPR/XL-PE
C=150
• C값 낮을수록 마찰손실 증가 → 최상층 잔류압 감소 → 관경 상향 필요 가능
• Hazen-Williams 공식: hf = 10.67·L·Q1.852 / (C1.852·D4.87)
🔴 급수압 (kPa)
마찰손실 반영 → 최상층 잔류압 · 감압밸브 판정
• 잔류압 < 최저 필요수압(세정밸브 100 · 샤워 70 · 일반 55 kPa) → 가압 또는 기구 변경
• ≥ 550 kPa : 감압밸브 또는 조닝 (KDS 31 30 15 4.7)
📋 관재질별 배관 지지 간격 기준 (별표 8 표 1)
강관: 20A↓=1.8m · 25~40A=2.0m · 50A=3.0m · 65~100A=4.0m · 125A↑=5.0m
동관/STS: 20A↓=1.0m · 25~40A=1.5m · 50A=2.0m · 65~100A=2.5m · 125A↑=3.0m
PVC관: 동관/STS와 동일 기준 적용

🗂️ 사용 절차 (4단계)
1
🏢 건물 정보 입력
상단 「급수·급탕 관경」 탭을 선택합니다.
① 건물 용도 선택 (아파트·사무소·호텔·병원 등)
② 사용 용도 구분 선택 → 주거용(아파트·단독주택) / 공용(그 외 모든 용도)
③ 층수 및 층높이(m) 입력
④ 급수압(kPa), 유속(m/s), 관재질 설정
2
🚿 위생기구 수량 입력
위생기구 목록에서 각 기구 수량을 입력합니다.
• 세면기, 양변기(세정탱크/세정밸브), 소변기, 욕조, 샤워기, 싱크대 등
• 급수·급탕 WSFU 와 배수 DFU 가 자동 계산됩니다.
• 💡 Tip: 기구를 0으로 두면 해당 기구는 계산에서 제외됩니다.
3
⚡ 관경 자동 산정
「관경 산정」 버튼을 누르면 결과가 즉시 표시됩니다.
• 급수관 / 급탕관 / 배수횡관 / 배수수직관 / 통기관 관경 자동 결정
• 급수: 순간최대유량 → 유속 기준 관경 · 배수: KDS 표 대조
• 최상층 잔류압·환탕 배관 필요 여부·감압밸브 설치 여부 자동 판정
• 결과 하단에 설계 근거(계산 과정)가 함께 표시됩니다.
4
📄 결과 출력 및 저장
상단 탭 「A4 보고서」 또는 「모바일 미리보기」를 선택합니다.
• A4 인쇄: 브라우저 인쇄 기능으로 PDF 저장 또는 종이 출력
• 이미지 저장: 결과를 JPG 이미지로 저장 (모바일 친화적)
• 오배수 탭: 오배수·통기 관경 별도 산정 가능
