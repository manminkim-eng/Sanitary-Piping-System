위생배관 관경을 즉시 산정할 수 있습니다

설치 상태 확인 중...
✅

이미 설치되어 있습니다!

급배수관경 앱이 홈 화면에 설치되어 있습니다.
앱 아이콘을 탭하면 바로 실행됩니다.

📱 앱으로 설치하면
⚡
빠른 실행
홈 화면 아이콘 탭 → 앱처럼 즉시 실행
📡
오프라인 지원
인터넷 없이도 관경 산정 가능
🖥️
전체 화면
브라우저 UI 없이 넓은 작업 화면
🔄
자동 업데이트
새 버전 배포 시 자동으로 최신 유지
💡
Chrome 또는 Samsung Internet을 사용하세요. 상단 📲 지금 앱 설치하기 버튼이 보이면 바로 탭하세요!
1
Chrome에서 열기

Android Chrome 브라우저에서 앱 주소를 입력하거나, 주소창에 직접 입력하세요.

🌐Chrome 브라우저 권장
2
설치 배너 탭

화면 하단 "앱 설치" 배너 또는 상단 📲 지금 앱 설치하기 버튼을 탭하세요.

📲설치 배너 또는 버튼 탭
3
설치 확인

팝업에서 "설치"를 탭하면 홈 화면에 아이콘이 추가됩니다!

🎉홈 화면 아이콘 추가 완료
⚠️
Safari 브라우저 필수! Chrome·Firefox에서는 홈 화면 추가가 지원되지 않습니다.
1
Safari에서 열기

반드시 Safari 브라우저에서 앱 주소를 입력하세요.

🧭Safari 필수
2
공유 버튼 탭

화면 하단 가운데 공유 버튼 □↑ 을 탭하세요.
(iPad는 상단 주소창 옆)

□↑공유 버튼 탭
3
홈 화면에 추가

공유 시트를 아래로 스크롤해서 "홈 화면에 추가"를 탭하세요.

➕"홈 화면에 추가" 탭
4
추가 확인

앱 이름을 확인하고 오른쪽 상단 "추가"를 탭하면 완료!

🎉오른쪽 상단 "추가" 탭
💡
Chrome 또는 Edge에서만 PC 앱 설치가 지원됩니다. 상단 📲 지금 앱 설치하기 버튼을 클릭하세요!
1
Chrome / Edge로 열기

Google Chrome 또는 Microsoft Edge에서 앱 주소를 입력하세요.

🌐Chrome 또는 Edge
2
주소창 ⊕ 아이콘 클릭

주소창 오른쪽 끝에 나타나는 ⊕ 아이콘을 클릭하거나, 상단 📲 지금 앱 설치하기 버튼을 클릭하세요.

⊕주소창 오른쪽 설치 아이콘
3
설치 확인

팝업에서 "설치"를 클릭하면 바탕화면과 시작 메뉴에 앱이 추가됩니다.

🖥️바탕화면 앱 아이콘 생성
